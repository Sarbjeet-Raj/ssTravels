## 🚀 Getting Started

### 1. Run Locally
Inside the project directory:
```bash
# Install dependencies (if not already done)
npm install

# Start the Vite development server
npm run dev
```
Open your browser at `http://localhost:5173/` (or the port Vite indicates).

### 2. Build for Production
```bash
# Typecheck and bundle optimized production build
npm run build
```
The output files will be cleanly bundled in the `dist/` directory.

### 3. Preview Production Build
```bash
npm run preview
```

## 🌐 Deployment Instructions

### Option A: Vercel (Recommended)
1. Push this folder to GitHub or deploy via Vercel CLI:
   ```bash
   npx vercel
   ```
2. Framework preset will automatically detect **Vite**.
3. Build command: `npm run build`
4. Output directory: `dist`

### Option B: Netlify
1. Connect repository or run:
   ```bash
   npx netlify deploy --prod
   ```
2. Build command: `npm run build`
3. Publish directory: `dist`

### Option C: Cloudflare Pages
1. Select framework preset **Vite**.
2. Build command: `npm run build`
3. Output directory: `dist`
